Définition sémantique du Tafsir : 
- vient du verbe fasara = dévoiler
- proche de safara = découvrir/dévoiler une chose (comme voyage). Exemple : dévoiler les compagnons du voyage
- Ce mot a plusieurs sens dans le dictionnaire

Définition épistémologique : 
- Discipline qui nous permet de comprendre la parole d'Allah

> Une science qui traite des états du Coran selon les finalités du discours divin suivant la capacité d'interprétation humaine [Définition par l'imam Azarkachi]


### L'énigme des deux Corans

> Dis : "Parcourez la Terre et voyez comment Il a commencé la création. Puis comment Allah crée la génération ultime. Car Allah est Omnipotent." [Sourate 29 Al-'Ankabut verset 20](https://quran.com/fr/laraignee/20)

Pour lire et comprendre le Coran, il est nécessaire de maîtriser le Coran de la vie. 

### L'importance du Tafsir

- Comprendre le message d'Allah adressé aux hommes
- La dernière révélation
- Le Coran est le condensé de tous les messages apportés par les prophètes
- Le Coran est le remède pour les croyants

### Les conditions requises du Mofassir (exégète)

- La langue arabe
- La grammaire
- La morphologie
- La rhétorique
- Les différentes lectures du Coran
- Les fondements de la religion
- Les fondements du droit
- Le contexte des versets
- L'abrogé et l'abrogeant
- Le droit (le fiqh)
- Les hadiths expliquant le Coran
- La science infuse

> Celui qui tombe sur la cause de révélation d'un verset, tombe sur un trésor

### Les différentes catégories de Tafsir

- Tafsir selon les textes : le fait d'interpréter une ayah par une autre ayah. Utiliser le corpus du Coran en entier
- Tafsir selon la raison
- Tafsir selon l'illumination

### Point de vue de l'imam des mofassirins

Ibn Abass dit : le Tafsir est classé selon quatre types
- Le sens connu par nature dans le langage des arabes : des termes accessibles dans le Coran que les arabophones comprennent
- Le sens que toutes personnes est censé connaître : par exemple "al hamdulilah"
- Le sens connu uniquement par les savants
- Le sens que seul Allah connaît : exemple : l'heure
